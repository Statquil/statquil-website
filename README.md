# Statquil Technologies

Static website for Statquil Technologies Private Limited.

## Preview

Open `index.html` in a browser, or run:

```sh
python3 -m http.server 8123
```

Then visit `http://127.0.0.1:8123`.

## Deploy

Upload the contents of this folder to the root of the GitHub repository.
The site has no backend, build step, external scripts or third-party requests.

Contact: contact@statquil.com
